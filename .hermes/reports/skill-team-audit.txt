   build/deployment process tidak otomatis.

7. Environment mismatch: SQLite (test) vs MySQL (production) — query
   MySQL-specific bisa lolos test.

8. No E2E / integration test: tidak ada Cypress/Pest Dusk untuk frontend,
   tidak ada API contract validation.

9. Missing .env.example vars: BILLING_FAKE, BILLING_GATEWAY, BILLING_GATEWAY_URL
   tidak ada di .env.example.
