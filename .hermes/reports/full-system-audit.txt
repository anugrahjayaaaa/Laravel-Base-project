1.1 THE AGENT (HERMES)
---

Hermes adalah satu model CLI agent — bukan sistem multi-agent terorchestrasi.

Model utama: poolside/laguna-s-2.1:free (via Nous Research provider)
Fallback provider: syngts.hermes.local.9router (localhost:20128/v1)

Konfigurasi utama (~/.hermes/config.yaml):
- agent.max_turns: 150
- agent.verbose: false
- agent.reasoning_effort: medium
- Plugins aktif: agency-agents-router, ponytail
- Terminal backend: local, timeout 180s, persistent cwd
- Web backend: firecrawl, use_gateway: true
- Browser backend: browser-use, cloud_provider, use_gateway
- Memory: enabled, 2200 char (notes), 1375 char (user profile)
- Compression: enabled, threshold 0.5, target ratio 0.2

Toolset tersedia:
- browser_exec          — drive web browser via Browser Use CLI
- clarify               — bertanya ke user (1-5 pertanyaan per turn)
- delegate_task         — spawn subagent terisolasi (max 10 paralel)
- execute_code          — Python persistent session (stdlib + Hermes deps)
- memory                — persistent memory (user notes + user profile)
- patch/read_file/write_file/search_files — file manipulation
- terminal              — shell commands (persistent, cwd persisten)
- todo_list             — task tracking
- tool_search/tool_describe/tool_call — lazy-loaded deferred tools
- vision_analyze        — load gambar untuk analisis
- web_search/web_extract — pencarian & ekstraksi web
- text_to_speech        — TTS

Deferred tools (dimuat via tool_search):
- agency_agents tools (4): delegate, inspect, load, search
- computer_use (1): desktop automation via cua-driver
- cronjob (1): schedule jobs
- image_gen (1): generate images
- terminal tools (1): process_manage (poll/wait/kill)

WORKFLOW AKTUAL
---

User request
    ↓
AI baca konteks (AGENTS.md, CLAUDE.md, docs/*.md) [selalu pertama]
    ↓
AI scan kode (terminal, read_file, search_files, grep)
    ↓
AI cek skill relevan via skill_view(name) [jika tersedia]
    ↓
[UI tasks:] AI propose A/B/C/D + concern review [untuk flow/UI tasks]
    ↓
AI buat perubahan (patch, write_file)
    ↓
AI jalankan verifikasi: php artisan test, pint, php -l
    ↓
[UI tasks:] AI cek rendered HTML (serve/curl atau browser)
    ↓
AI commit + push + buat PR (terminal + gh CLI)
    ↓
User review PR di GitHub
    ↓
[Bug ditemukan:] user report → kembali ke scan
    ↓
Document update (docs/, ADR) jika behavior berubah

ARCHITECTURE
---

Layered architecture (clean):
  HTTP Layer (web Blade / API JSON)
    → Controller (validate + dispatch)
      → Service / Form Request / Observer
        → Eloquent Models (SoftDeletes)
          → MySQL (InnoDB, utf8mb4)

Cross-cutting: auth, rbac(can: middleware), feature(feature: flag), log-activity, force-json

Status: BAIK. Clean separation of concerns. Good dependency direction. Low coupling antar layer.
